SK BRAIN - PRIVACY VALIDATION PACKAGE
Exact code under test: commit @SHA@
Branch: @BRANCH@   (NOT integrated; nothing here is a release)

WHAT THIS DOES
It runs the privacy tests for the SK Brain on your Windows computer, using only the folder
you unzip. It never opens, copies or changes your everyday SK Assistant, its databases or
its settings. Every test file and database is created inside this folder (in "test_area")
and can be deleted afterwards. The tests also refuse network connections and name lookups.

WHAT YOU NEED
Windows with Python 3.14 (the same Python you used for the earlier Brain checks) and the
internet ONCE. The first step you run creates a private environment inside this folder
(.venv-check) and installs only pypdf there - the same pinned, hash-checked PDF reader the
official Brain Windows check installs. Nothing is installed into your own Python.
If "py -3.14" worked for you before, this works too.

DO IT ONE STEP AT A TIME
1. Unzip the whole zip to a simple place, for example  C:\SKcheck  (right-click the zip,
   "Extract All"). Open the unzipped folder "SK-Privacy-Validation-@SHA7@".
   You do NOT need to close SK Assistant.

2. Double-click  STEP1_CHECK_PACKAGE.bat
   Takes a few seconds. It proves the code in this folder is exactly commit @SHA7@.
   You should see:  PACKAGE CHECK: OK ...   then   FINISHED: PASS
   Check that the line "Git tree id (recomputed)" shows the same number I gave you in the
   chat (@TREE@). Also compare the zip's SHA-256 if you
   like:  certutil -hashfile <zipfile> SHA256   (I give you the expected value in the chat).
   Press any key to close the window.

3. Double-click  STEP2_RUN_PRIVACY_TESTS.bat
   Takes about 1 to 3 minutes. At the end you should see a list of nine lines that all
   start with [PASS], and the last lines:  RESULT: PASS   commit @SHA7@...
   A report file called  privacy_check_report.txt  appears in the same folder.

4. Double-click  STEP3_RUN_BREAK_TESTS.bat
   Takes roughly 10 to 20 minutes (about 95 deliberate breaks; it prints one line per break).
   It breaks a COPY of the code on purpose and checks that the tests notice.
   At the end:  RESULT: PASS   deliberate breaks ...
   Some lines say "same-as-before (equivalent, expected)" - that is normal and explained
   on the screen. A report file  privacy_breaks_report.txt  appears.

5. (Optional, about 15 minutes) STEP4_OPTIONAL_FULL_SUITE.bat runs every test in the repo.

6. Send me the two report files (privacy_check_report.txt and privacy_breaks_report.txt),
   or just tell me the last "RESULT:" line of each step. If anything says FAIL, send the
   report file and do not worry - nothing was changed on your computer.

IF A STEP DOES NOT START
- "Could not find Python": open Start, type  cmd , press Enter, type  py -3.14 --version
  and tell me what it prints.
- Windows SmartScreen asks about the .bat file: choose "More info" then "Run anyway".

WHEN YOU ARE DONE
You can delete the whole folder. Nothing else on your computer was touched.

WHAT IS IN THE FOLDER
source\            the exact code of commit @SHA7@ (unchanged)
tools\             the scripts these steps run
MANIFEST.txt       the commit id, the git tree id and a fingerprint of every file
test_area\         created when you run the tests; safe to delete
