# Decisions

One file per decision: `NNNN-short-title.md` (numbered in order, never reused).

```
# NNNN Title
Status: proposed | approved by the owner on <date> | superseded by NNNN
Context: why a decision was needed (two or three lines).
Decision: what was decided.
Consequences: what it changes, what it rules out, follow-up work.
Approval: the owner's words or a reference to them (owner decisions only).
```

Earlier decisions (B1 - B6, up to 2026-11-09) are recorded in
`../DEVELOPMENT_NOTES.md`, under "SK Brain milestones" and each milestone's
section; they are not copied here.
